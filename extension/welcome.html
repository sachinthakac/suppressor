Welcome to Suppressor

Blurs what you don't want to see. Everything is classified on your machine.

Waiting for the classifier… Checking http://127.0.0.1:8765 every 3 seconds.

Suppressor needs a small classifier server running on this computer. Keyword matches are blurred without it, but deciding why an item is about your topic (spoilers or news?) happens in the server. It takes two steps:

  1. 1

    Download the server bundle

    Get suppressor-server-….zip from the latest release and unzip it anywhere.

  2. 2

    Run the setup script

    It installs the classifier and starts it. The first run downloads the model (about 2.3 GB).

    Windows powershell -ExecutionPolicy Bypass -File .\setup.ps1
    macOS / Linux bash setup.sh
  3. ✓

    This page turns green

    As soon as the server answers. Then pick what to hide: GTA VI spoilers are set up as an example.

Running the server on another port? Change it under Options › Advanced.
